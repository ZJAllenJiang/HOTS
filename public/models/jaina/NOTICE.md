# Jaina community model candidate

Character mesh and original texture: Blizzard Entertainment (Heroes of the Storm).
Original Warcraft III port: Razorclaw_X. Modified model/animations: JohnWalk.
Additional animation sources include Stefan.K and Warcraft III Classic/Reforged assets.
Source: https://www.hiveworkshop.com/threads/jaina-proudmoore-hots-with-new-animations.363866/

This is a community-modified port, not an untouched native HOTS asset. Game artwork is not covered by the application source-code license. Contributor permission is not a separate Blizzard license. See docs/assets/jaina-source-audit.md and tools/model-conversion/source-readme.html for full credits and limitations.

Converted body: 10,537 triangles, embedded 1024×1024 PNG, 38 skeletal animation clips. Warcraft III particles, ribbons and replaceable glow are omitted. Current gameplay abilities remain prototypes.
