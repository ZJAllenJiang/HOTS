# HOTS — 浏览器单线乱斗（设计阶段）

目标：浏览器直接运行、接近 Heroes of the Storm 的 5v5 单线战斗体验，云端开发与部署。

**当前只有设计提案，尚无可运行游戏。** 没有安装依赖、生成游戏工程或部署服务。

- [完整设计与技术路线比较](docs/superpowers/specs/2026-11-06-browser-aram-design.md)
- [OpenSpec 提案](openspec/changes/browser-aram-foundation/proposal.md)
- [里程碑与验收任务](openspec/changes/browser-aram-foundation/tasks.md)
- [需求场景](openspec/changes/browser-aram-foundation/specs)

推荐路线：TypeScript + Three.js + 共享纯模拟核心；先素材/手感样片，再 5v5 人机，再权威服务器私人联机。Unity 是备选，不是已排除的技术。
