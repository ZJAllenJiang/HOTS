# Correct 3D fidelity, pace and desktop support

The user rejects 2D fallback and generic hero resemblance. Preserve cloud development and private hosting. Prioritize one real hero before expanding the roster.

Acceptance:
- Only WebGL 3D is playable; failure/context loss stops simulation and explains recovery.
- A real self-contained hero GLB can be loaded with skeleton and animation lifecycle; placeholder status remains explicit until real assets pass visual acceptance.
- Minion waves and fights leave readable response time without slowing player input. Deterministic tests and measured match samples document the change.
- Mouse, Control-click and single-button trackpad controls plus bounded rendering quality presets are available; physical Mac/Windows validation remains a separate required gate.

See `docs/changes/2026-11-08-3d-correction.md` for parameters, evidence and the source-asset blocker.
